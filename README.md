# 森声App

森声是一款帮助用户放松和专注的声音应用，提供自然环境音效和白噪音。

## 功能特点

- **多种声音效果**：包括雨声、森林声、篝火声、海浪声等自然环境音效
- **AI语音控制**：通过语音命令控制播放、暂停和调节声音
- **个性化设置**：自定义声音组合和保存收藏
- **自适应界面**：支持移动设备和网页端访问

## 技术栈

- React Native / Expo
- Expo Router
- TypeScript
- Web Speech API (Web版)

## 安装与运行

1. 克隆仓库
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/forest-sound-app.git
cd forest-sound-app
```

2. 安装依赖
```bash
npm install
```

3. 本地运行
```bash
npm start
```

4. Web版构建
```bash
npm run build:web
```

5. 部署到GitHub Pages
```bash
npm run deploy
```
